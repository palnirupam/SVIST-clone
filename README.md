# SVIST - 1:1 Pixel-Perfect Clone

A 100% pixel-perfect, responsive clone of the [Swami Vivekananda Institute of Science and Technology (SVIST)](https://svist.org/) official website, reconstructed using modern reverse engineering and automated DOM extraction.

---

## 🚀 Live Preview
You can deploy this repository directly with **GitHub Pages** or **Vercel** with zero configuration.

### How to Enable GitHub Pages:
1. Go to this repository's **Settings** tab on GitHub.
2. Under **Code and automation**, select **Pages**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Your site will be live at `https://palnirupam.github.io/SVIST-clone/`!

## ✨ Features & Sections Included
- **Exact Styling & Theme:** Reconstructed with the original Tailwind CSS palette (`brand-700`, `brand-500`, `brand-950`).
- **Typography:** Web fonts linked with `Playfair Display` and `Manrope`.
- **Accurate Statistics:** Live-hydrated data:
  - 2008 Established
  - 30+ Industry MoUs (Bosch, Capgemini)
  - ₹9 LPA Top TCS Offer (2025 batch)
  - 950+ Job Offers Given (2024-26 batches)
- **Interactive Elements:**
  - Continuous running news marquee & recruiters logo carousel.
  - Interactive "Quick Admission Enquiry" form with feedback validation.
  - 8 Departmental programme cards (B.Tech CSE, AI & DS, ECE, EEE, ME, CE, MBA, Diploma).
  - Why SVIST feature cards, Alumni Testimonials, and Placement statistics.
  - Campus Guided Tour video modal with high-res aerial campus backdrop.
  - Floating WhatsApp chat button & responsive mobile navigation drawer.
